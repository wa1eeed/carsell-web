# CarSell — carsell.one

سوق سيارات سعودي: بيع مباشر · تفاوض بالعروض · مزاد بسعر احتياطي · لوحات · خدمات · ضمان.

## ابدأ من هنا

1. اقرأ `docs/BUILD-WEB-ADMIN.md` كاملًا — **عقد التنفيذ**، وكل ما فيه إلزامي.
2. اقرأ `docs/HANDOFF.md` — قواعد العمل والبنية والتوطين والأداء.
3. اقرأ `docs/DESIGN-DECISIONS.md` — قرارات مُلزِمة تتقدّم على المواصفة عند التعارض.
4. افتح مراجع التصميم من `design/` في المتصفح مباشرة (لا خادم مطلوب).

## المراحل

- **المرحلة ١ (الآن):** الويب العام + لوحة الأدمن + قاعدة البيانات + API → نشر.
- **المرحلة ٢:** تطبيق Flutter على نفس الـAPI.
- **المرحلة ٣:** لوحة التاجر.

## المكدّس

Next.js 15 · TypeScript strict · Postgres 16 + Prisma · Tailwind v4 · TanStack Query · Zod · next-intl · Cloudflare R2 · Resend · Sentry · Coolify

## قواعد لا تُخالف

1. **التصميم هو الحقيقة.** إن تعارض الكود مع التصميم، الكود خطأ.
2. لا لون أو مسافة أو ظل مكتوب في مكوّن — التوكنات فقط.
3. المكوّنات الأساسية قبل الشاشات. الشاشة تركيب لا رسم.
4. كل رقم بـ Arial، والعرض بالأرقام العربية-الهندية.
5. جلسة تطوير = مهمة واحدة من القسم ١٠ في عقد التنفيذ.
6. `prisma migrate deploy` في الإنتاج — **لا** `db push` أبدًا.
7. لا ملف يُكتب على قرص الحاوية — كل وسائط إلى R2.
