## قواعد تصميمية ثُبِّتت

- **اللوحة السعودية**: أبيض بإطار `#1a1a1a` ٢px وخطّ Arial — معالجة واحدة في كل الشاشات.
- **الأسطح الداكنة**: `--carz-ink` و`--carz-dark` فقط.
- **الوضع الضريبي**: حقل واحد `is_vat_registered` — لا ثلاث فئات. والشارة تتبعه لا نوع البائع.
- **الفاتورة الصادرة لا تُعدَّل بأثر رجعي** عند تغيير الحالة الضريبية أو العمولة أو القواعد.
- **الشريط المثبَّت**: كل إطار له شريط سفليّ مثبَّت يحمل حشوًا سفليًّا بمقداره وارتفاعًا يتّسع للمجموع.
